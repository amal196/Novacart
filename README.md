# 🛒 NovaCart - Modern React E-Commerce Store

> Helping users discover, save, and shop products through a modern and seamless e-commerce experience.

NovaCart is a modern e-commerce web application built using React and Vite, designed to provide an engaging online shopping experience through product discovery, wishlist management, cart functionality, and responsive design.
